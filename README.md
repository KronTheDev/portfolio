# portfolio

Andrew Pie (KronTheDev) — portfolio and CV, served by GitHub Pages at [kronthedev.xyz](https://kronthedev.xyz).

Static HTML/CSS/JS in English, French and Ukrainian. Preview with `python3 -m http.server 8080`.

To update projects, experience, skills or the CVs, edit the locale files in `tools/locales/` (`en.py`, `fr.py`, `uk.py`, one per language, same keys in each) and run `python3 tools/build_site.py`.
